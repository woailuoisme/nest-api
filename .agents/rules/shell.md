# Shell 与 CLI 规范

## 1. 工具选型

| 传统     | 改用    | 说明                          |
| :------- | :------ | :---------------------------- |
| `grep`   | `rg`    | 尊重 `.gitignore`，多线程     |
| `find`   | `fd`    | 语法简洁，智能大小写          |
| `sed`    | `sd`    | 仅限 Markdown / 注释 / 纯文本 |
| 任意命令 | `rtk …` | 压缩输出，节省上下文          |

## 2. 执行纪律

1. 终端命令统一加 `rtk` 前缀；`rtk` 不可用时直接执行原命令。
2. 禁止 `cd`：用工具自带路径参数（`-C` / `--dir` / 绝对路径）锚定工作区。
3. 安装、构建、脚本一律非交互（`-y` / `--non-interactive` / `--batch`），不得挂起等待输入。
4. 代码源文件的批量改写不走正则（见 `ast-grep.md`），`sd` 只用于非代码文本。
